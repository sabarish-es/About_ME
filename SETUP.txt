# Sabarish GitHub Profile — STATIC image version

This version uses LOCAL SVG images stored inside `assets/`.

Upload these files to the root of your profile repository:
- README.md
- assets/

No GitHub Actions and no third-party stats image server are required for these images to display.

IMPORTANT:
The stats card is a visual snapshot based on the values visible in your current GitHub profile screenshot. It is intentionally static so it will display immediately. If you want live auto-updating statistics later, we can add GitHub Actions after the basic version is working.
